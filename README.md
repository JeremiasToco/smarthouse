

## Sobre Smart WhereHouse

Smart WhereHouse é uma aplicação web que faz a gestão da base de dados de um armazem que contém equipamentos de telecomunicações. 
Neste armazem tanto o gestor, como o funcionario que faz a entrega do material do armazém terão acesso aos produtos existente no armazem, produtos que ja terminaram em stock,  como os produtos que estão danificados no armazem.
